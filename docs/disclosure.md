# 商业服务与闭源模型披露

本文按「调用环节、数据流向、权限范围、费用假设、可替代性、锁定风险」逐项说明 Cabinhug 运行时会接入的每一个商业服务与闭源模型。所有服务都可以不配置：未配置时系统以确定性 Fake 或本地 Mock 运行，数据不出本机，行为差异在每节末尾注明。软件依赖的许可证清单另见仓库根目录的 [THIRD-PARTY.md](../THIRD-PARTY.md)，数据来源与合规说明见 [data/README.md](../data/README.md)。

价格均为供应商官网 2026-09-11 查到的标价，币种人民币，不含税务与汇率变化；实测用量来自本项目开发环境 `llm_usage` 表最近 30 天（2026-08-12 至 09-11）的记录，不代表生产负载。

## 1. 一览

| 服务 | 用在哪 | 出网的数据 | 密钥与权限 | 未配置时 |
|---|---|---|---|---|
| DeepSeek（`deepseek-flash`） | 意图理解、五个 Agent 的模型循环、应答表述、带图的表述、联网搜索工具 | 用户当轮文本、检索片段、脱敏后的档案摘要；带图轮附照片 / 帧序图 | `DEEPSEEK_API_KEY`，仅推理接口 | 确定性 Fake 模型，编排链路可跑、回答是模板 |
| 阿里云百炼 / 通义千问 | 照片观察层（定位 + 描述）、图标目录向量、可选的 ASR / TTS 档 | 用户照片、图标裁图、语音片段或待合成文本 | `DASHSCOPE_API_KEY` | 观察层关闭，模型只看文字；语音落本地档 |
| 火山方舟 / 豆包 | 语音识别（`doubao-seed-2-0-mini`）、语音合成（`seed-tts-2.0`） | 麦克风片段（唤醒后）、待合成文本 | `ARK_API_KEY`、`BYTEDANCE_TTS_API_KEY` | 本地 ASR 容器 / 终端系统 TTS |
| 阿里云 AI 安全护栏 | 输入与输出的内容审核、提示词攻击检测 | 用户输入与模型输出全文 | RAM AccessKey，只需内容安全调用权限 | 本地规则筛与脱敏仍运行，审核层按 fail 策略降级并留痕 |
| RAGFlow Cloud | 三个知识库数据集的检索与文档管理 | 检索词；导入时上传手册 markdown | `RAGFLOW_API_KEY`，数据集读写 | 检索标记未接入，不伪造出处 |
| 高德开放平台 | 驾车路径规划、天气、地理编码、POI 搜索、两端地图底图 | 起终点坐标、地名 | `AMAP_SERVER_KEY`（服务端）、`AMAP_JS_KEY` + 安全码（终端底图） | 天气回退 Open-Meteo，路径规划标记未接入，终端程序化底图 |
| MinerU | 知识库导入前 PDF 转 markdown，离线工具 | 手册 PDF | `MINERU_API_TOKEN` | 直接上传已有 markdown |
| Google Calendar / CalDAV | 保养预约写入真实日历（可选后端） | 预约标题、时间、地点 | OAuth refresh token / CalDAV 账号 | Mock 日历回执 |

## 2. 逐项说明

### 2.1 DeepSeek

- **调用环节**：`agent-runtime` 经 Vercel AI SDK 直连（意图理解、应答表述、带图表述、联网搜索）；五个业务 Agent 的模型循环在 `pi` 子进程里，经 ACP 协议调用同一个模型。默认模型 `deepseek-flash`（DeepSeek-V4.1-Flash），带图请求同样落在它上（`DEEPSEEK_VISION_MODEL`）。用量按**响应里的模型名**记入 `llm_usage`，别名切换不会记错。
- **权限范围**：一把 API key，只有推理权限，无回调、无 webhook、不授权任何写操作。
- **费用假设**（官网 2026-09-10 起生效价，元 / 百万 token，闲时 = 高峰的一半）：

  | 计费项 | 闲时 | 高峰（工作日 9–12、14–18 点） |
  |---|---|---|
  | 输入·缓存命中 | 0.02 | 0.04 |
  | 输入·缓存未命中 | 1 | 2 |
  | 输出 | 4 | 8 |

  实测最近 30 天：2586 轮真实对话、18.4M token（输入 14.7M，其中缓存命中 5.8M；输出 3.7M）。按上表折算 **24 元（全闲时）到 48 元（全高峰）**，即每轮 0.9–1.8 分，每轮均 7.1k token。仓库内的估算器（`LLM_PRICE_*_PER_1K`）同期记 77 元，单价取的是旧档，偏保守；控制台财务页展示的是估算值，对账以供应商账单为准。
- **可替代性**：provider 是配置级，`@ai-sdk/openai-compatible` 已接通义千问；`CABINHUG_LLM=fake` 为离线档。换模型不改编排代码。
- **锁定风险**：① 上下文缓存命中率约 40%，换供应商后成本结构会变；② 思考模式的默认值随厂商版本变化（请求层已显式声明，并有测试守着）；③ 提示词按 DeepSeek 的行为调过，换模型要重跑评测集。
- **可复现性影响**：评测 real 档的数字依赖模型版本；fake 档不依赖。

### 2.2 阿里云百炼 / 通义千问

- **调用环节**：照片观察层的定位（`qwen3-vl-flash`）与描述（`qwen3-vl-plus`），两遍可分别切到 DeepSeek 或端侧检测器；图标目录向量（`qwen3-vl-embedding`）；ACR-015 的语音档（`qwen3-asr-flash` / `qwen3-tts-flash`）。
- **权限范围**：一把 `DASHSCOPE_API_KEY`，只有模型调用权限。
- **费用假设**（华北 2 北京，元 / 百万 token，≤32K 档）：`qwen3-vl-flash` 输入 0.15 / 输出 1.5；`qwen3-vl-plus` 输入 1 / 输出 10；两者各有 100 万 token 免费额度（开通后 90 天）。语音档以百炼计费页为准（第三方整理：ASR 约 1.1 元 / 小时，TTS 约 0.8–1 元 / 万字符）。一张仪表照片两遍约 3–5k token，按上表不足 0.05 元。
- **可替代性**：观察层两遍各自可换（`CABINHUG_VISION_DETECT_PROVIDER` / `_DESCRIBE_PROVIDER`）；语音档可换火山或本地。
- **锁定风险**：图标目录的向量维度绑定 embedding 模型，换模型要 `kb:icons --rebuild` 整表重建。

### 2.3 火山方舟 / 豆包

- **调用环节**：网关经 Ark 接口用 `doubao-seed-2-0-mini`（多模态模型的音频输入）做语音转写；语音合成经网关 `/v1/tts/speech` 调 `seed-tts-2.0`，密钥只在服务端。
- **权限范围**：`ARK_API_KEY` 与 TTS key 只有推理权限。
- **费用假设**：`doubao-seed-2.0-mini` 官网价输入 0.2 / 输出 2 元 / 百万 token（≤32K）；豆包语音合成按量付费，字数包 10 万字起售，单价以火山计费页为准。实测 30 天 323 次转写，平均 3.8 秒一次；估算合计不到 0.3 元。
- **可替代性**：ASR 有阿里云档与本地容器档，TTS 有阿里云档与终端系统 TTS；三档全过网关，切换是后台配置。
- **锁定风险**：低。本系统侧另有 `ASR_DAILY_CALL_LIMIT` / `TTS_DAILY_CHAR_LIMIT`（缺省 8 万字 / 日）闸门，超限降级而非拒绝；它们不是账单上限。

### 2.4 阿里云 AI 安全护栏

- **调用环节**：`guardrails` 内容管线第二层，对五个 Agent 的输入与输出统一生效；本账号实测只开了内容审核与提示词攻击两个维度，个人信息检测由本地脱敏层负责。
- **权限范围**：RAM 子账号 AccessKey，仅内容安全调用权限，不含任何资源管理权限。
- **费用假设**：文本审核（高级）15 元 / 万次，提示词攻击检测 15 元 / 万次（2026-01-22 起收费），按量后付费，开通不收费。每轮对话输入、输出各审一次，约 0.3 分 / 轮。实测 `guard_audit_logs` 累计 5476 条裁决（放行 4987、拒绝 489），含本地规则层的裁决。
- **可替代性**：`GUARD_PROVIDER=openai-compat` 可指向自建或本地审核模型，接口形状相同。
- **锁定风险**：审核维度的开关在阿里云控制台而不在代码；本仓的策略开关只能关不能开。

### 2.5 RAGFlow Cloud

- **调用环节**：`rag` 包对三个数据集做检索（带出处），隔离在调用层按 Agent 强制；`kb:*` 命令做文档上传、替换、解析状态检查。
- **权限范围**：API key 对本账号数据集有读写权限。
- **费用假设**：云端订阅按套餐计费（第三方转述的入门档约 49 美元 / 月，以 cloud.ragflow.io 账单为准），embedding 模型所在的模型账号**另计**，欠费表现为解析零篇、检索零命中。竞赛期间使用的是【填：当前套餐档位】。
- **可替代性**：RAGFlow 本体 Apache-2.0，可自托管，HTTP API 相同；切片与面包屑逻辑在本仓 `prepareMarkdownForChunking`，不依赖云端功能。
- **锁定风险**：切分方法与数据集 id 在云端配置；迁移要重新上传语料并重跑 `kb:qa` 校验块长分布。**数据流向**：厂商手册的 markdown 会上传到第三方云端，部署方须确认自己有权这样使用这些资料。

### 2.6 高德开放平台

- **调用环节**：服务端 Web API（驾车路径规划、天气、地理编码、POI 搜索），两端 JS 底图。
- **权限范围**：服务端 key 只开 Web 服务；JS key 配安全码并限制域名。
- **费用假设**：个人认证开发者免费一年，月配额基础 LBS 15 万次、搜索 5000 次、天气 5000 次；超额 30 元 / 万次（阶梯折扣）。竞赛期间未超过免费配额。
- **可替代性**：天气自动回退 Open-Meteo（CC-BY 4.0）；路径规划无等价免费替代，未配置时标记未接入而不是编一条路线。
- **锁定风险**：坐标系为 GCJ-02，POI id 与路线方案格式是高德专有；出发导航把带途经点的方案交给高德 App 执行，这一跳与高德强绑定。

### 2.7 MinerU

- **调用环节**：只在知识库导入前把 PDF 转成 markdown（`kb:convert`），运行时不调用。
- **费用假设**：每账号每日 2000 页高优先级免费额度，超出降级排队。
- **可替代性**：直接上传已有 markdown；或本地跑开源 MinerU。

### 2.8 Google Calendar / CalDAV

- **调用环节**：保养预约确认后写入真实日历（M43-02），默认 Mock。
- **权限范围**：Google 用 OAuth 客户端 + 一次授权换 refresh token，只申请日历事件写权限；CalDAV 用应用专用密码。
- **费用**：免费。
- **锁定风险**：无，两种后端并列，`both` 模式可同时写。

## 3. 闭源模型说明

| 模型 | 使用范围 | 为什么用它 | 替代方案 | 迁移成本 | 对可复现性的影响 |
|---|---|---|---|---|---|
| DeepSeek-V4.1-Flash | 全部文本推理与带图表述 | 中文能力、价格、上下文缓存 | 通义千问（已接）、任意 OpenAI 兼容模型 | 改配置 + 重跑评测集（约半天） | real 档评测数字随模型版本变；fake 档不受影响 |
| Qwen3-VL-Flash / Plus | 照片观察层两遍 | 定位准确率在对照中最好 | DeepSeek 视觉档、端侧 YOLO 检测器（AGPL，见 THIRD-PARTY） | 改两个环境变量 | 观察层评测集可复跑对照 |
| Qwen3-VL-Embedding | 图标目录向量 | 图文同空间 | 任意图文 embedding | 整表重建 | 相似度阈值要重新标定 |
| Doubao-Seed-2.0-mini / Seed-TTS-2.0 | 语音转写与合成 | 中文口语延迟低 | 通义千问语音档、本地 ASR 容器、系统 TTS | 后台切换 | 语音链路 smoke 用固定音频 |
| 阿里云安全护栏模型 | 内容审核 | 合规维度覆盖 | 自建 OpenAI 兼容审核端点 | 改一个环境变量 | 红队评测集可复跑，拦截率会变 |

## 4. 费用与运行边界

有界的部分：单轮 ACP 提示超时、分支超时 300 秒、fan-out 汇聚 60 秒、行程审核预算 90 秒 / 3 轮、AI SDK 对 429 最多重试 3 次并有 2 秒退避地板、ASR 与 TTS 日限额、后台探针限流。

没有的部分：**没有账单级的硬上限**。供应商侧的余额与配额是最终闸门，控制台财务页展示余额历史与按 provider 的吞吐，用于人工盯。竞赛期间全部服务的月费用在百元量级。
