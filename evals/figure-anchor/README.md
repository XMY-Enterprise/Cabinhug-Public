# 手册图锚定评测（`eval:figure-anchor`，ACR-029）

> 度量对象：手册里的一张图能否定位到讲它的那一段。锚错段比没图更糟：检索把图连同错误的段落
> 一起交给表述模型，模型会把两者当成一回事讲给车主。因此这是一道闸门：准确率不到 90% 不接检索（`run.ts` 退出码非 0）。

## 文件

| 文件 | 内容 |
|---|---|
| `fixtures/<doc>-p<from>-<to>.json` | MinerU `content_list.json` 的块表（只留 type / bbox / page_idx / text / text_level / img_path / 图注 / 脚注），`meta.pageOffset` 换算回原 PDF 页序号。**图片文件不进仓库**——锚定只看坐标与文字。块表含厂商手册正文，版权属于厂商，可能不在本树；不在时本评测与 `rag` 的真块表用例不可运行 |
| `cases.jsonl` | 真值：每张图「可接受的锚定块下标」集合（`expected`），以及页码、种类、备注 |
| `run.ts` | 跑 `anchorFigures` 于块表，按总 / 种类 / 规则分列准确率；`--json` 落 `evals/runs/figure-anchor.json`；`--list` 打印全部锚定结果供补真值 |

判定本体（五条规则）在 `enterprise/backend/shared/rag/src/figures.ts`，单测在同包 `test/figures.test.ts`；这里只放数据与 runner（ACR-014 的分工）。

## 实测（ACR-029 第 1 步探针，2026-09-11）

MinerU（mineru-3.4.5，经官方 API）转换并保留整个 zip，对象是 Model 3 车主手册的两段切片（第 8~40 页「概述」、第 146~152 页「充电」，`pdftocairo` 切页）：

| 项 | 实测 |
|---|---|
| zip 内容 | `full.md`、`images/`（158 + 13 张 jpg，按内容 sha256 命名）、`*_content_list.json`、`*_content_list_v2.json`、`layout.json`、`*_model.json`、原 PDF |
| `content_list.json` 字段 | `text` 块：`bbox / page_idx / text / text_level(标题才有)`；`image` 块：`bbox / page_idx / img_path / image_caption[] / image_footnote[]`；另有 `header / footer / page_number / aside_text` |
| 块数 / 图数 | 第 8~40 页：958 块 / 158 图；第 146~152 页：234 块 / 13 图 |
| 图注覆盖率 | 1 / 158（脚注 11 / 158）；充电段 0 / 13。车主手册上不能靠图注锚定 |
| 「引用句」出现率 | 含「下图 / 如图 / 参阅图 / 图中 / 插图」的正文块 6 / 677（充电段 1 / 194），几乎全是「注：下图仅作示范」 |
| 图的尺寸 | 长边 < 页宽 12% 的小图（指示灯、按钮、警告三角）89 张；中 24；大插图 45 |
| 阅读顺序 | 按栏不按行：指示灯页的块表是「7 枚图标 → 7 段说明」，图与说明在顺序上隔 6 个块。按"相邻块"锚定会把第一枚锚到第七段 |
| MinerU 漏抽 | 第 33 页「警告：打开中控台时…」那句没有出成文本块（图标出了）；第 16 页左栏两枚 ESC 图标没有出成图块。锚定管不到这些 |

因此规则以坐标为主（同行 / 同栏），图注与引用句只是加分项。

## 真值怎么来的

`cases.jsonl` 的 57 条（42 张小图、15 张插图 / 截图，覆盖 9 页）逐张对照页面渲染图目视核对写下，不取自算法输出。
第 26 页「从车内打开车门」的插图与第 33 页手套箱插图（图在右栏最顶上，算法取了下方的「注」）在核对时锚错，
规则据此加了「栏顶的图接上一栏末尾那段」，所以这两条不是盲测；其余 55 条算法首次即通过。
待人复核（尤其 15 张插图的判断）；复核改动直接改 `expected`，不改算法。

## 迈锐宝（三栏版式）补的真值（2026-09-11）

`fixtures/malibu-owners-full.json` 是 2017 雪佛兰全新迈锐宝用户手册全本的块表（191 页 / 3009 块 / 195 张图，`kb:convert` 落盘）。
`cases.jsonl` 里 `mb-` 开头的 39 条同样是对着页面渲染图目视写的，覆盖 13 页：指示灯页（4-16 / 4-17 / 8-23）、儿童保护装置（2-26 ~ 2-29）、仪表（4-10 / 4-11）、收音机（6-5 / 6-6）、制动（9-13）、头枕与座椅（2-2）。

这本手册的版面与特斯拉几乎相反，规则为此增加三条（增加前迈锐宝为 30/39）：

| 版面事实 | 特斯拉 | 迈锐宝 | 加的规则 |
|---|---|---|---|
| 栏数 | 两栏 | **三栏**，一栏里几段常顶着同一个 x 起笔 | `columnSplits` 按块数不按左边界数、每个够宽的空当都是栏界；空当 ≥ 25% 页宽时一侧一块也算 |
| 指示灯 | 图标在左、说明在右同一行 | **图标居中在标题下，说明在下面**；竖长到 153 单位 | icon 阈值 12% → 16% 页宽；没有同行说明的小图取下面那段，栏底的接下一栏开头 |
| 图注 | 158 张 1 张 | 有，且下一段以图注开头（「下固定钩（A）是…」） | `caption` 规则：上 / 下段呼应图注 |
| 栏顶的图 | 下面是「注：…」，讲它的在上一栏末尾 | 下面就是正文 | 栏顶的图：下面是正文取下面，是「注」才接上一栏 |

## 局限

- 锚定量了特斯拉 40 页 + 迈锐宝全本 13 页的 96 张图；下一本新版式的手册进来前，先 `kb:figures --dry` 看规则分布，再补 20 条真值。
- 图召回只量了文字提问一路；照片路（crop → 整图 / crop 向量）只有真跑冒烟里的一张仪表照（同枚图标 0.88），没有成集的负样本。
