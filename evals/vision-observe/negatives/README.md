# 负样本集

负样本用于量误接受率。本目录放三类：

1. **别的车型的仪表照片**——图标相似但目录里没有（M71-03 的 `--match` 量误接受率）。
2. **非仪表照片**——路面、机舱、随手拍的室内。
3. **手册里的干净图标**——检验观察层不会因为"太干净"而报出高置信的警示灯。

登记方式与 `../photos/README.md` 相同；在 `../cases.jsonl` 里写 `"negative": true, "items": []`。
现有 20 张（M79-01 入库），第 1 类为空。

## 判据：27 个符号里没有一个亮着

判据不采用观察层的结论：整帧 1920×1080 里一枚图标只有 30 px，观察层会漏报亮着的近光灯与驻车灯
（15 张候选中 7 张有灯，观察层均报零警示灯）。筛选用确定性的颜色判据（`enterprise/backend/vision-trainer/vision_trainer/tools/pick_negatives.py`：
图标列里偏离该列背景色 > 12 的像素数，无灯是 0、有灯是 604–1024），**再人眼逐张过放大的图标列**。
815 帧经此筛选剩 13 张，人眼确认均无灯，全部入库。

¹ 其中 3 张（`neg-05` / `neg-08` / `neg-09`）屏幕定位落在屏内的面板上，图标列裁偏，颜色分数不作数；
改为放大整帧确认左侧图标列为空。

## 第 2 类：与车无关的 App 界面截图（7 张）

`provenance` 为 `internal-eval-only`：用户 2026-09-09 提供的 UI 参考图，原始出处未知，
只作内部评测，不进任何对外材料。M76 合成集训出的检测器把这 7 张全部误报为
`seatbelt_unfastened`（置信 0.27–0.51），入库为这条回归提供分母。

入库时不缩放：按 1280×720 存时同一模型在这些图上为 0/7，被误报的橙色应用图标缩小后不再触发，
回归基线随之消失。这 7 张按原分辨率存 JPEG（质量 92，共 3.3 MB）。
