# 上海 → 广州 自驾大交通分支（drive）· 本轮

燃油车、带老人小孩、4 天游玩。上海→广州单程约 1500 公里，往返各拆两天、中途宿吉安，节奏适合老人小孩。

## 去程（两天）
- 出发日：上海沿 G60 沪昆向西至江西吉安（约 730km）。每 2 小时进服务区歇一次（桐庐/上饶/鹰潭服务区），燃油满油出发，中途补一次油，宿吉安。

## 回程（两天，镜像）
- 第 3 日晚：广州 → 吉安；第 4 日：吉安 → 上海。
